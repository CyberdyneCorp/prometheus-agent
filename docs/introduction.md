# Prometheus Agent

Prometheus is a personal AI agent shipped as one `prometheus` binary (alias
`pmt`) that serves every surface as a subcommand.

## How these docs are made

The pages under **Reference** are generated by `cargo xtask gen` from the
same typed definitions the binary uses: the configuration reference from the
`config.toml` schema, the CLI reference from the command tree and the error
catalog from the exit-code and error tables. They are never edited by hand,
and `scripts/check` fails when a checked-in page differs from a fresh
generation, so a default is stated in exactly one place: the code.

Build the site locally with `mdbook build docs`; the output lands in
`target/docs/`.
